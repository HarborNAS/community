# HarborOS Community

Welcome! This is the public place to report HarborOS bugs, ask configuration questions, suggest features, and talk with other users. You do not need to know which source-code repository owns a problem to report it here.

## Get help or share feedback

| What you need | Where to go |
| --- | --- |
| Something is broken | [Report a bug](https://github.com/HarborNAS/community/issues/new?template=bug_report.yml) |
| Help with setup, configuration, or usage | [Ask a question](https://github.com/HarborNAS/community/issues/new?template=question.yml) or [Community Q&A](https://github.com/HarborNAS/community/discussions/categories/q-a) |
| A feature or improvement | [Request a feature](https://github.com/HarborNAS/community/issues/new?template=feature_request.yml) or [Discuss an idea](https://github.com/HarborNAS/community/discussions/categories/ideas) |
| General conversation or sharing your setup | [Browse Discussions](https://github.com/HarborNAS/community/discussions) |

## How to submit a bug or question

1. [Search existing issues](https://github.com/HarborNAS/community/issues?q=is%3Aissue) and [discussions](https://github.com/HarborNAS/community/discussions) to see whether someone has already reported it. Add useful details to an existing report instead of opening a duplicate.
2. Sign in to GitHub, open the **Issues** tab, and click **New issue**, or use a link above.
3. Choose a form and describe what happened or what you want to accomplish. For bugs, include the steps to reproduce and expected behavior. Add your HarborOS version/build and relevant hardware or app details if available; write "unknown" if you cannot find the version.
4. Submit the issue. Follow the conversation on that issue and reply there if more information is needed. GitHub's **Subscribe** button lets you follow updates.

Screenshots and logs are optional. Remove passwords, access tokens, serial numbers, and personal information before uploading anything. All issues and discussions here are public.

If you are unsure whether something is a bug or a configuration question, either form is fine. Please open one report per separate problem. Maintainers can classify the report or link it to the relevant project.

## Issues and Discussions

**Issues** provide a place to track bugs, support questions, and feature requests. **Discussions** provide community Q&A, ideas, feedback, and conversation. In the Q&A category, the author or a maintainer can mark a helpful reply as the answer. Existing Bug discussions remain available; new bug reports should preferably use Issues for tracking.

## Documentation

The documentation source repository is [HarborNAS/docs](https://github.com/HarborNAS/docs). If the documentation website is unavailable or does not cover your question, use the question links above. You do not need the documentation website to submit a report.
